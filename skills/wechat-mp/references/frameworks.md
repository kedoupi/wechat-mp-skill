# Frameworks（四选一，覆盖常见公众号）

选定一个主框架写 `brief.md`，不要混成四不像。

## 1. 干货清单

**何时用：** 读者要「步骤 / 清单 / 对照表」。  
**结构：** 问题 → 原则 → 3–7 条可执行项 → 边界 → 下一步。  
**禁忌：** 列表项空泛（「注重质量」）；每条要有可观察结果。

## 2. 观点判断

**何时用：** 你有清晰立场，要说服或划线。  
**结构：** 判断句开场 → 论据 2–4 点 → 反方 → 适用边界 → 行动。  
**禁忌：** 两边讨好导致无判断；用情绪代替论据。

## 3. 热点解读

**何时用：** 有时效事件，但读者要的是「对我意味着什么」。  
**结构：** 事件一句话 → 常见误读 → 你的解释框架 → 对读者的含义 → 可做之事。  
**禁忌：** 复述新闻占篇幅；无核实的数据/内幕。

## 4. 复盘

**何时用：** 项目/决策事后总结。  
**结构：** 背景目标 → 过程关键节点 → 结果 → 归因（可控/不可控）→ 可迁移教训。  
**禁忌：** 只有成功叙事；缺少「下次会改什么」。
